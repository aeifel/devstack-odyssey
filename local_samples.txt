### Setup replication set in mongodb instance before this
'''
Use mongosh --host hostname:port

>>> rs.initiate()

AND make sure the host name in rs.conf() -> members, matches the host name in connector config
Else modify the rs.conf with:

>>> cfg = rs.conf()
>>> cfg.members[0].host = "DESIRED_HOSTNAME:27017"
>>> rs.reconfig(cfg, {force: true})
'''
